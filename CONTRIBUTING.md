
# Guia de contribucion

Gracias por tu interes en colaborar con Tienda TECSUP.
Esta guia explica como reportar errores y proponer mejoras
para mantener el proyecto organizado.

## Reportar un error

Si encuentras un problema:

1. Revisa si el error ya fue reportado.
2. Describe el problema encontrado.
3. Indica los pasos para reproducirlo.
4. Explica cual seria el resultado esperado.

## Proponer una mejora

Para proponer una nueva funcionalidad:

1. Explica que mejora deseas incorporar.
2. Indica como beneficiaria al proyecto.
3. Describe brevemente como podria implementarse.
4. Espera la revision de la propuesta.

## Proceso para colaborar

1. Haz un fork del repositorio.
2. Clona tu copia:

```bash
git clone https://github.com/chrismontes-lab/tienda-tecsup.git
```

3. Crea una rama para tu cambio:

```bash
git checkout -b mejora/nueva-funcionalidad
```

4. Realiza los cambios y pruébalos.
5. Guarda los cambios:

```bash
git add .
git commit -m "Describe la mejora realizada"
git push origin mejora/nueva-funcionalidad
```

6. Abre un Pull Request para que los cambios sean revisados.

## Checklist para Pull Requests

Antes de enviar una contribucion, verifica:

- [ ] El cambio cumple con el objetivo propuesto.
- [ ] El codigo funciona correctamente.
- [ ] No se han eliminado funciones existentes.
- [ ] Se mantiene el orden de los archivos.
- [ ] Se actualizaron los documentos necesarios.
- [ ] El Pull Request explica los cambios realizados.

## Recomendaciones

- Utilizar nombres claros para variables y funciones.
- Mantener una estructura ordenada.
- Evitar modificar archivos que no esten relacionados con la mejora.
- Probar los cambios antes de publicarlos.

Gracias por ayudar a mejorar Tienda TECSUP.
